# LUMÉ Dental Care

A realistic, patient-first dental clinic website demo built for a modern Indian dental practice.

## What this version focuses on

- Real clinic-style information architecture
- Online appointment flow
- Treatment discovery with indicative pricing
- Dentist profiles
- Clinic/location finder
- Phone and WhatsApp actions
- Patient reviews
- Clinic experience and facilities
- FAQ and first-visit guidance
- Responsive desktop, tablet and mobile layouts
- Sticky mobile actions for Book / Call / WhatsApp / Clinic
- Appointment modal with service, clinic and preferred-time selection

The UX is informed by patterns visible on current dental clinic websites, including prominent appointment booking, clinic discovery, treatment navigation, reviews, safety/technology information and mobile-first contact paths. It is an original implementation rather than a pixel-for-pixel copy of another clinic's site.

## Run locally

Open `index.html` directly or use VS Code Live Server.

## Production upgrades

Connect the appointment form to a real backend/calendar, replace demo content and imagery with the clinic's verified information, add Google Maps/clinic APIs, implement analytics, SEO/schema markup and deploy to Vercel/Netlify/GitHub Pages.
