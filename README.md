# LUMÉ Dental Studio — Demo Website

A premium dental clinic demo created for client acquisition and portfolio use.

## Included
- Responsive navbar and mobile menu
- Premium hero and trust metrics
- Studio / clinic experience section
- Treatments
- Before / after showcase placeholder
- Doctor profiles
- Testimonials
- FAQ
- Consultation form with demo interaction
- Responsive mobile/tablet layouts
- Scroll reveal animations

## Run locally
Open `index.html` in a browser or use VS Code Live Server.
